# Preguntas frecuentes

## Que es Asistto?

Asistto es un asistente virtual con IA para WhatsApp. Atiende mensajes, responde preguntas, captura prospectos y ayuda a automatizar la atencion a clientes.

## Asistto reemplaza a mi equipo?

No. Asistto ayuda a resolver lo repetitivo y a filtrar conversaciones. El equipo humano sigue atendiendo casos importantes, ventas avanzadas o situaciones que requieren criterio humano.

## Que ventajas tiene un chatbot con IA?

- Responde rapido, incluso fuera de horario.
- Reduce preguntas repetitivas para el equipo.
- Captura datos de prospectos de forma ordenada.
- Ayuda a no perder oportunidades por tardar en contestar.
- Puede calificar leads antes de que los tome una persona.
- Puede conectarse a herramientas como calendarios, CRMs o sistemas internos si el proyecto lo permite.

## Que necesita el cliente para empezar?

Normalmente se necesita:

- Tener claro que quiere automatizar.
- Preguntas frecuentes del negocio.
- Informacion de servicios, horarios, precios o procesos.
- Un numero de WhatsApp o decision sobre usar uno nuevo.
- Un CTA: agenda, formulario, landing o contacto humano.
- Si habra integraciones, acceso tecnico o documentacion de la API correspondiente.

## Puede funcionar con mi WhatsApp actual?

Puede revisarse. En muchos casos se puede trabajar con WhatsApp Cloud API usando un numero preparado para el bot. La configuracion exacta depende del estado del numero, Meta Business y necesidades del cliente.

## Puede agendar citas?

Si. El paquete PRO contempla agenda con calendario. Para crear citas reales en calendario se necesita configurar la integracion correspondiente, por ejemplo Google Calendar u otra herramienta compatible.

## Puede conectarse a mi sistema?

Si el sistema del cliente tiene API o una forma segura de integracion, Asistto puede conectarse para consultar, crear o actualizar informacion. Esto requiere revision tecnica.
